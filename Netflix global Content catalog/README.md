# Netflix global Content catalog 
This project provides a comprehensive Overview of netflix global contents by Analyzng key metrics  to support data driven decision-making.
# Key Metrics
key metrics/KPI like total titles, total movies, total tv shows etc were used in the analysis to solve question to make data-driven decisions

# Data Preparation
Transformed data using phyton, Cleaned raw data, Handled inconsistent values and created table with exsisting columns (explode) for analysis.

# Dashboard Features
KPI cards summarizing key performance indicators
interactive charts and visual
slicer for better data exploration
clean and user friendly layout
Readable fpr non-technical individual
sheets conected to the dashboard (brief, insights etc)

# How to use 
Download the pbix file from this repository
Open it using power bi
